# AutoSplit Timer

Minecraft Java Edition 1.12.2向けのクライアント側タイマーMODです。設定したSTART、LAP、GOALの判定範囲を通過すると、自動で計測と区間記録を行います。

## 動作環境

- Minecraft 1.12.2
- Minecraft Forge 14.23.5.2859
- Java 8

MCEFなどの追加MODは必要ありません。

## 導入

1. Minecraft Forge 1.12.2を導入します。
2. `autosplittimer-0.1.0.jar`をMinecraftの`mods`フォルダーへ入れます。
3. ワールドに入り、`Y`キーで設定画面を開きます。

キー設定はMinecraftの「操作設定」から変更できます。`/ast gui`でも設定画面を開けます。

## 基本操作

1. 「新規コース」からコースを作成します。現在地にSTARTが作られます。
2. プレイヤーを移動させ、「現在地に変更」や「現在地をラップとして追加」で各地点を設定します。
3. STARTを通過すると計測が始まり、LAPを通過すると区間が記録され、GOALで終了します。

判定方式はOn GroundとAABBから選べます。複数ブロックの範囲選択、HUDの表示項目・順番・位置・色・大きさの変更にも対応しています。

## コースの共有

コース設定画面の「コースを共有」から`.astcourse`ファイルを書き出せます。記録を含めるかどうかは書き出し時に選択できます。「コースを読み込む」から受け取ったファイルを読み込めます。

共有ファイルには座標が含まれるため、作成時と同じマップで使用してください。

## 補足

- コース名や地点名へ日本語を入力する場合は、入力欄に`Ctrl+V`で貼り付けてください。
- 設定と記録は`.minecraft/config/autosplittimer/`に保存されます。
- このMODはプレイヤーの移動やテレポートを行いません。マルチプレイでの利用可否は各サーバーのルールを確認してください。
- LiveSplitとは無関係の非公式MODです。
